# Teacher Review — Acid-Base Concept Inventory (15–20 min)

Use this to get the teacher's verdict on the 15-item paper quiz (separate from the lab app itself,
which they've already checked). Items are from `concept-inventory-acid-base.md` §4, unchanged since.

**How to run it:** read each question aloud or hand them the printed form, let them answer in their
own words, and write down what they actually say next to each line — not a rephrasing of what you
hoped they'd say. A text message or voice note back to yourself right after also works; type it up
after. The point is a record that exists outside your memory.
